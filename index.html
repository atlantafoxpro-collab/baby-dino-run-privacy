Baby Dino Run - Privacy Policy

Effective Date: September 30, 2026

Baby Dino Run ("the App") is a casual running game that provides single-player and real-time multiplayer gameplay with friends.

1. Information Used by the App

Baby Dino Run does not require users to create an account, provide an email address, provide a telephone number, or log in.

During multiplayer gameplay, users may choose a player name or nickname. This name is transmitted between participating players using WebRTC so that players can be identified during the game.

Game scores may also be exchanged between participating players and stored locally on participating devices as part of the multiplayer gameplay experience.

2. Information Stored on Devices

Baby Dino Run may store the following information locally on participating devices:

  • Player name or nickname
  • Game scores and gameplay-related information

This information is used to provide the game's functionality.

3. Multiplayer and WebRTC

Baby Dino Run uses WebRTC technology for real-time multiplayer communication between participating players.

Player names and gameplay information required for multiplayer functionality may be transmitted between participating devices.

Baby Dino Run does not maintain a central database containing player names, game scores, or multiplayer room codes.

Multiplayer room codes are used to establish a game session and are not stored by the App after the session.

4. Network Information

The App requires network connectivity for multiplayer functionality.

Baby Dino Run does not intentionally collect or store users' IP addresses and does not use an analytics service to track users.

Network communication required to establish and maintain multiplayer connections may involve technical network information inherent to Internet communication and WebRTC.

5. Accounts

Baby Dino Run does not require user registration or user accounts.

No email address, telephone number, password, or social-media account is required to play the game.

6. Advertising and Analytics

Baby Dino Run currently does not display advertisements and does not use third-party advertising SDKs.

The App does not currently use analytics or tracking services.

7. Sharing of Information

Baby Dino Run does not sell personal information.

Information used during multiplayer gameplay, such as player names and gameplay scores, may be shared directly between participating players as necessary to provide the multiplayer functionality.

The App does not share this information with advertising networks or analytics providers.

8. Children's Privacy

Baby Dino Run is not specifically designed to collect personal information from children.

The App does not require an account, email address, telephone number, or other registration information.

Multiplayer participants may choose player names that are visible to other participants in the same multiplayer game. Users should avoid entering sensitive personal information as their player name.

9. Data Security

Baby Dino Run does not maintain a central user database containing player names or game scores.

The security of information transmitted during multiplayer gameplay also depends on the network and communication technologies used by participating devices.

10. Data Deletion

Because player names and scores are stored locally on participating devices, users can remove locally stored game information by clearing the App's data or uninstalling the App, depending on the device and App functionality.

Information received by another multiplayer participant may remain on that participant's device until it is deleted by that participant.

11. Changes to This Privacy Policy

This Privacy Policy may be updated when the App's functionality or data practices change.

Any updated version will be made available at this same Privacy Policy URL.
